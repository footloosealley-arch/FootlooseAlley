# Footloose Alley Studio Manager v3.9.0

## Classes Management

- Added the Classes dashboard with search and day, program, and status filters.
- Added class creation and editing, active-instructor assignment (including Unassigned), capacity management, and non-destructive activation/deactivation.
- Added readable loading, empty, and error states with toast feedback for mutations.
- Added an idempotent migration that seeds 48 weekday fitness, weekend fitness, dance, and salsa schedule entries in 24-hour time format.
