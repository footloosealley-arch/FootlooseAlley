# Footloose Alley Studio Manager v3.14.0

## Branded mobile icon and vibrant interface

- Added installable web-app metadata so phones use the official Footloose Alley logo, open directly to the dashboard, and display the studio brand colour.
- Added official logo metadata for browser tabs, shortcuts, Apple home-screen installs, and the web-app manifest.
- Refreshed the shared application background, page headers, top bar, sidebar, active navigation, and user avatar with energetic Footloose Alley red, rose, amber, and teal accents.

No SQL migration is required for this release.
