# Footloose Alley Studio Manager v3.8.0

## Instructor Management

- Added a production instructor-management route at `/instructors`.
- Added total, active, and inactive instructor summaries, search, and status filtering.
- Added validated create and edit workflows backed by the existing `Instructors` table.
- Added reversible activate/deactivate controls instead of permanent deletion.
- Added one-click phone and WhatsApp contact actions.
