# Footloose Alley Studio Manager v3.13.0

## Membership automation workspace

- Added a dedicated Memberships page with live totals for active, expiring, expired, frozen, and unstarted memberships.
- Added a daily priority list that brings expired memberships, upcoming renewals, and outstanding balances to the top.
- Added search and status filters across all student memberships.
- Added one-click WhatsApp renewal reminders with safe Indian phone-number normalization.
- Added direct links to each student profile, where the existing membership engine handles activation, renewal, freeze, reactivation, cancellation, and history.
- Displayed the official plan prices for Monthly, 3 Months, 6 Months, and Yearly memberships.
- Replaced the former Memberships sidebar link to Fee Dues with the new dedicated route while leaving Fee Dues available at its existing URL.
- Preserved payment receipts, Google Forms intake, private student photos, Supabase authentication, and database/RLS behavior.

No SQL migration is required for this release.
