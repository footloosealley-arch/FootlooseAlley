# Footloose Alley Studio Manager v3.18.0

## Responsive desktop and mobile experience

- Added a persistent mobile bottom navigation for Home, Students, Attendance,
  Follow-ups, and the complete app menu.
- Improved the mobile side menu so it closes immediately after selecting a
  destination.
- Added safe-area spacing for installed iPhone and Android home-screen apps.
- Improved phone header sizing, touch targets, page spacing, and form controls.
- Added mobile-friendly full-height dialog behavior for long forms.
- Added a dedicated attendance card workflow on phones, with large Present,
  Absent, and Leave controls and a sticky Save Attendance action.
- Improved the Students toolbar for one-handed mobile use.
- Added a consistent 1600px desktop workspace so wide screens use space
  efficiently without stretching content excessively.

## Safety

- No database, Supabase, authentication, RLS, payment, receipt, membership,
  intake, photo, attendance-history, or follow-up behavior changed.
- No SQL migration, Edge Function deployment, or new secret is required.
