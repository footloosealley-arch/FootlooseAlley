# Footloose Alley Studio Manager v3.17.0

## Attendance Intelligence follow-ups

- Added an actionable Attendance Follow-ups section to the existing Attendance Intelligence page.
- Flags active students with no present attendance for seven or more days.
- Flags three or more consecutive absences.
- Flags attendance below 50% when at least four classes were marked during the past 30 days.
- Added Open, Urgent, Away 7+ Days, and Below 50% totals.
- Added search plus risk-reason and status filters.
- Added reviewed WhatsApp “we missed you” messages; staff always confirm and send the message themselves.
- Added Complete, Tomorrow, and 1 Week actions.
- Added attendance risks to the main Daily Follow-up Center.

## Security and data safety

- Extended the existing staff-only follow-up action system to support Attendance.
- Existing Row Level Security and active administrator/receptionist checks remain in force.
- Attendance history, students, class schedules, fees, memberships, payments, receipts, intake forms, and private photos are not modified by risk calculations.
- Completing or postponing an alert stores only the staff action.
- No message is sent automatically.
