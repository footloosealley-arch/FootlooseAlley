# Footloose Alley Studio Manager v3.16.0

## Daily Follow-up Center

- Added a dedicated Follow-ups workspace for active administrators and receptionists.
- Combined membership renewals, overdue fees, enquiry follow-ups, trial reminders, and student birthdays into one live priority list.
- Added reviewed WhatsApp message links; staff always confirm and send the message themselves.
- Added Complete, Tomorrow, and 1 Week actions so staff can clear or postpone reminders.
- Added search plus type and status filters for open, postponed, and completed work.
- Added live Open, Urgent, Due Today, and Postponed totals.

## Security and data safety

- Added a small reminder-action table protected by Row Level Security.
- Only active studio staff can read reminder actions or call the completion and postponement RPCs.
- Existing students, enquiries, trials, memberships, fees, payments, receipts, intake forms, and private photos remain the source of truth and are not duplicated or silently modified.
- No message is sent automatically.
